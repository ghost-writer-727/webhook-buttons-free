# Webhook Buttons for WooCommerce (free version)

Adds buttons to the WooCommerce order screen. One click sends that order's data as JSON to a webhook URL you choose: n8n, Make, Zapier, Pabbly Connect, Power Automate, or any URL that accepts a JSON POST.

- Install from WordPress.org: https://wordpress.org/plugins/webhook-buttons/
- Support forum: https://wordpress.org/support/plugin/webhook-buttons/
- Pro version (custom fields, flat data, staff notes, user access control, sample sends, auth header): https://noblestrategies.dev/webhook-buttons

This repository mirrors each release of the free version exactly as shipped on WordPress.org, including the readable source of the settings page (`react-settings-ui/src`). Issues and pull requests are welcome. Licensed GPL-2.0-or-later.
